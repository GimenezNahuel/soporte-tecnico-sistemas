# Soporte técnico a sistemas e infraestructura

Este repositorio documenta procedimientos operativos y casos prácticos de resolución de incidentes y solicitudes operativas en entornos de sistemas corporativos, abarcando gestión de identidades y accesos (Directorio Activo / RBAC), diagnóstico de conectividad remota mediante VPN y recuperación de servicios en infraestructura de servidores.

## Estructura del Repositorio

* **Guía de Soporte de Sistemas**: Procedimiento estándar para validación de accesos, diagnóstico remoto y gestión de incidentes en servidores.
* **Casos de Estudio (Simulación de Service Desk)**:
  * **Caso #SYS-01 (Alta y Provisión de Accesos en AD)**: Creación de cuenta corporativa y asignación de grupos de seguridad para nuevo ingreso (`INC0012853`)[cite: 1, 2, 4].
  * **Caso #SYS-02 (Falla de Acceso a Unidad Compartida / VPN)**: Diagnóstico remoto y restablecimiento de túnel VPN corporativo (`INC0012847`)[cite: 8, 11, 12].
  * **Caso #SYS-03 (Caída Masiva de Servicio de Impresión)**: Identificación de saturación en servidor de impresión y recuperación del servicio (`INC0012870`)[cite: 20, 21, 22, 24].
