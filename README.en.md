# IT Systems & Infrastructure Technical Support

This repository documents standard operating procedures and practical incident resolution case studies in corporate IT systems environments, covering identity and access management (Active Directory / RBAC), remote VPN connectivity troubleshooting, and server infrastructure service recovery.

## Repository Structure

* **Systems Support Guide**: Standard operating workflow for access provisioning, remote troubleshooting, and server incident response.
* **Case Studies (Service Desk Simulation)**:
  * **Case #SYS-01 (Active Directory User Provisioning & RBAC)**: Account creation and security group assignment for an incoming employee (`INC0012853`)[cite: 1, 2, 4].
  * **Case #SYS-02 (Shared Drive Access Failure / VPN)**: Remote workstation troubleshooting and VPN tunnel restoration (`INC0012847`)[cite: 8, 11, 12].
  * **Case #SYS-03 (Office-Wide Print Service Outage)**: Root-cause isolation on a degraded print server and service recovery (`INC0012870`)[cite: 20, 21, 22, 24].
