# Guía de Soporte de Sistemas

1. **Altas y Accesos (IAM):** Validar datos del usuario, crear la cuenta y asignar únicamente los grupos de seguridad correspondientes al rol/departamento[cite: 1, 2, 4].
2. **Fallas de Acceso Remoto:** Si falla una unidad de red interna pero hay Internet/correo, revisar el estado del cliente VPN y el túnel corporativo antes de escalar[cite: 8, 11, 12].
3. **Incidentes Masivos en Servidores:** Consultar el estado de los nodos en Sala de Servidores para aislar qué servidor está degradado o saturado y reiniciar el nodo afectado validando luego con el usuario[cite: 20, 21, 22, 24].
