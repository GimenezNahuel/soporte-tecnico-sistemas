# Systems Support Guide

1. **Provisioning & Access (IAM):** Validate user details, create the account, and assign only the security groups required for the role/department[cite: 1, 2, 4].
2. **Remote Access Issues:** When internal network drives fail despite working internet and email, verify VPN client and tunnel status first[cite: 8, 11, 12].
3. **Server Outages:** Check Server Room nodes to isolate degraded or overloaded servers, restart the affected node, and confirm recovery with the reporting user[cite: 20, 21, 22, 24].
